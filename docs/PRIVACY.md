# 개인정보·법적 검토 체크리스트 (PRIVACY)

이 문서는 법률 자문이 아니라 **법무 검토를 요청하기 위한 사실 정리와 기술적 선택지**입니다. 결론은 법무가 내립니다.

## 1. 이 서비스가 다루는 개인정보

| 데이터 | 포함 가능성 | 처리 |
|---|---|---|
| 작업 사진 | 고객 집 내부, 가구·소지품, 드물게 사람 얼굴, 주소가 적힌 서류 | 기본은 **저장하지 않음**(해시·메타·분석 결과만). `INSPECTOR_PHOTO_STORE_DIR` 설정 시 REVIEW/FAIL 건만 보존(기본 90일) |
| EXIF 위치(GPS)·촬영 시각 | 기사 위치 = 고객 주소 | 부정 검사에만 사용. DB에는 좌표가 결과 JSON 안에 저장됨 |
| 기사 식별자 | `technician_id` | 기사별 통계 집계 |
| 작업 메모 | 고객 상황 서술 가능 | VLM 프롬프트에 포함. 로그에는 기록 안 함 |

## 2. 외부 전송 (국외 이전)

- Claude 공급자를 쓰면 사진(리사이즈·EXIF 제거본)과 작업 메모가 Anthropic API(해외)로 전송됩니다. 개인정보보호법상 **개인정보의 국외 이전**에 해당할 수 있어 고지·동의 또는 계약상 근거가 필요합니다.
- 기술적 선택지:
  - `INSPECTOR_VLM_LOCAL_ONLY=true` 또는 카테고리별 `privacy.local_only: true`: 해당 사진은 로컬 모델(Ollama)로만 분석. 로컬 공급자가 없으면 분석 없이 REVIEW 처리(외부 전송 0건).
  - 요청별 `options.local_only: true`: 고객이 동의하지 않은 건만 로컬로.
  - 전송본은 최대 1568px JPEG이며 EXIF(위치·기기 정보)는 제거됩니다. 얼굴·서류 마스킹은 하지 않습니다.
- 법무 확인 사항: 위탁/국외 이전 고지 문구, 처리방침 반영, Anthropic 데이터 보존 정책(기본 30일 등) 확인.

## 3. 위치정보

- EXIF GPS는 기사가 촬영한 위치이며 고객 주소와 사실상 같습니다. 위치정보법상 수집·이용 동의 범위 확인이 필요합니다.
- 선택지: 기사 앱에서 GPS 제외하고 업로드(그러면 `gps_spread`/`gps_far_from_site` 검사는 비활성), 또는 좌표를 저장하지 않고 검사 후 폐기(현재는 결과 JSON에 남음 → 필요 시 마스킹 옵션 추가 가능).

## 4. 보존·파기

- 검사 결과 JSON: 보존 기간 정책 필요(감사 목적 vs 최소 보존). 현재 무기한.
- 사진: `INSPECTOR_PHOTO_RETENTION_DAYS` 로 자동 파기. 검수 완료 후 즉시 파기하려면 `PhotoStore.delete(inspection_id)` 호출 지점을 검수 API에 추가 가능.
- 해시(dHash)는 사진을 복원할 수 없는 64비트 지문이라 개인정보로 보기 어렵지만, 법무 판단 필요.

## 5. 접근 통제

- 모든 조회 API는 `X-API-Key`. 사진 조회(`/v1/inspections/{id}/photos/{photo_id}`)도 동일.
- 운영자 화면 접근은 사내망 또는 SSO 뒤에 두고, `INSPECTOR_CORS_ORIGINS`는 운영자 화면 도메인만.
- 로그에 사진·메모·좌표를 남기지 않습니다(`backend/observability.py`).

## 6. 이용자 고지 초안 (법무 수정 전)

> 작업 품질 확인을 위해 기사가 촬영한 작업 사진과 메모가 AI 분석 시스템에 전달될 수 있으며, 이 과정에서 사진의 축소본이 해외 소재 AI 서비스 제공자(Anthropic PBC)에 전송될 수 있습니다. 전송 시 위치 정보 등 메타데이터는 제거되며, 원본 사진은 검수 목적에 한해 최대 90일 보관 후 파기됩니다.
